# claude-plugins-frasalvi
Marketplace for my custom set of plugins for Claude Code

## Plugins

This repository contains the following plugins:

- **team-development**: A plugin for executing implementation plans with persistent worker teammates, one per code domain. Workers ask instead of guessing, runs and experiments stay with the lead and the user, and one whole-branch review gates paid runs and the merge. Companion to superpowers.
- **research-companion**: A plugin for brainstorming, evaluating, and deciding on research directions.
- **project-oversight**: A plugin for building and revising project roadmaps, with steps weighted Full, Light or Paired by how they will be worked.
- **pr-review-triage**: A plugin for triaging PR review comments inline (verify, fix or dismiss with evidence) and closing out the merge.
