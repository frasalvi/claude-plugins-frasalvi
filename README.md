# claude-plugins-frasalvi
Marketplace for my custom set of plugins for Claude Code

## Plugins

This repository contains the following plugins:

- **team-development**: A plugin for executing implementation plans with a team of persistent agent teammates — one worker per context domain, right-sized reviews, and a bounded fix loop. Companion to superpowers.
- **fork-development**: A plugin for executing implementation plans with forked subagents that inherit the session's context and prompt cache — sparse reviews per risky task and per review group, and a bounded fix loop. Companion to superpowers.
- **research-companion**: A plugin for brainstorming, evaluating, and deciding on research directions.
- **project-oversight**: A plugin for building and revising project roadmaps, with steps sized to one superpowers cycle or one plan-mode session.
- **pr-review-triage**: A plugin for triaging PR review comments inline (verify, fix or dismiss with evidence) and closing out the merge.
